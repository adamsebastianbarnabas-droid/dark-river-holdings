## 🚀 البدء السريع

### التشغيل المحلي

```bash
git clone https://github.com/adamsebastianbarnabas-droid/dark-river-holdings.git
cd dark-river-holdings
git checkout imperial-features

docker-compose up -d

curl http://localhost:8000/health
```
